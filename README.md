> A clean, responsive Nike website clone built with vanilla HTML, CSS, and JavaScript — no frameworks, no dependencies. Crafted as an internship project and opened for Hacktoberfest 2024 contributions.

---

## ✨ Features

- **Pixel-Perfect UI** — Faithful recreation of Nike's landing page layout, typography, and color language
- **Pure Vanilla Stack** — Zero dependencies; just HTML5, CSS3, and JavaScript working in harmony
- **Fully Responsive** — Fluid layout adapting gracefully across desktop and mobile viewports
- **Open Source** — Accepted Hacktoberfest 2024 PRs and community contributions

---

## 🛠 Tech Stack

| Technology | Role |
| :--- | :--- |
| **HTML5** | Semantic page structure and layout |
| **CSS3** | Styling, animations, and responsive design |
| **JavaScript** | Interactivity and DOM manipulation |
